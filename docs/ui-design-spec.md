# 维修工单助手 UI 设计稿

## 设计定位

面向个体维修师傅和小型维修店的“现场优先”工作台。核心目标是让用户在拿起手机后，先看到今天要处理什么、还有多少钱没收，再用最少的步骤完成一张工单。

设计关键词：简洁、可扫描、少输入、强反馈、离线可靠。

## 信息架构

```text
工作台
├─ 概览：今日数据、状态进度、最近工单、快捷入口
├─ 工单：搜索、筛选、推进状态、打开详情
└─ 客户：搜索客户、查看历史、直接新建工单

分析与系统
├─ 项目模板：常用服务项目与默认价格
├─ 统计复盘：工单、收入、收款状态
├─ 设置与备份：门店资料、显示、数据与演示数据
└─ 回收站：还原已移除工单
```

移动端保留四个一级入口：概览、工单、客户、设置；项目模板、统计和回收站从设置进入，避免底部导航拥挤。

## 视觉规范

### 色彩

| 用途 | 浅色模式 | 使用说明 |
| --- | --- | --- |
| 主色 | `#2858C9` | 新建、确认、推进等主操作 |
| 导航深色 | `#14213D` | 桌面端侧边栏，形成稳定工作区 |
| 画布 | `#F3F5F7` | 页面背景，降低长时间使用疲劳 |
| 卡片 | `#FFFFFF` | 主要内容容器 |
| 成功 | `#267D66` | 已完成、已收款 |
| 警示 | `#BD7A21` | 待确认、部分收款 |
| 风险 | `#BE5B51` | 未收款、取消、删除等需注意状态 |

颜色只表达状态和操作优先级，不用大面积渐变或装饰性插画。

### 字体与层级

- 页面标题：26 px / 800，最多两行。
- 区块标题：16 px / 800。
- 工单编号和金额：16–22 px / 800，编号可使用等宽字体。
- 正文：14 px / 400，行高 1.45。
- 辅助文字：12–13 px / 500，使用 `onSurfaceVariant`。
- 所有文本允许系统字体回退，长客户名、备注和大字体设置下不得溢出。

### 间距与形状

- 基础间距：4 / 8 / 12 / 16 / 24 / 32。
- 页面左右安全边距：手机 16 px，桌面内容区 24 px。
- 卡片圆角：14 px；输入框和按钮圆角：10–12 px。
- 卡片不使用明显阴影，以 1 px 轮廓和背景层级区分。
- 主要按钮高度 44 px，紧凑按钮不低于 40 px。

## 页面稿

### 概览

```text
┌─ 侧边栏 ────────┐ ┌─ 工作台 / OVERVIEW ─────────────────────────┐
│ 维修工单助手     │ │ 今天，先把现场安排好。             [新建工单] │
│                  │ ├──────────────────────────────────────────┤
│ ● 概览           │ │ 今日工单    待收款       已完成金额   客户档案 │
│   工单           │ ├──────────────────────────────────────────┤
│   客户           │ │ 工单进度              最近工单               │
│                  │ │ 待确认  维修中  待收款  已完成   编号 / 状态 │
│ 项目模板         │ ├──────────────────────────────────────────┤
│ 统计复盘         │ │ 快捷入口：新建工单  新建客户  项目模板         │
│ 设置与备份       │ └──────────────────────────────────────────┘
└──────────────────┘
```

首屏只放四类决策信息：今天有多少单、欠款多少、服务进度如何、最近打开哪张工单。

### 工单列表

- 顶部固定页面标题和“新建工单”。
- 搜索框优先，状态和收款筛选紧随其后。
- 每张工单只展示：编号、客户、设备、预约时间、收款状态、可推进动作。
- 详情和推进使用整张卡片点击；危险操作放在详情页的“更多操作”中。

### 工单详情 / 编辑

按服务流程分组：客户与设备 → 故障与项目 → 报价与收款 → 照片与签名 → 保修与备注。每组只保留一个主动作，保存后给出明确的成功反馈。

### 设置

一级设置使用列表入口，二级设置使用顶部返回条，避免在一个长页面里堆叠所有表单。数据备份操作统一使用带说明的动作卡，并在覆盖恢复前二次确认。

## 响应式规则

- `>= 900 px`：深色侧边栏 + 内容区，内容最大宽度 1180 px。
- `700–899 px`：隐藏侧边栏，内容区使用顶部页面标题和底部导航。
- `< 700 px`：单列卡片；操作按钮换行；指标卡两列；长列表保持 12–16 px 内边距。
- 任何宽度下，主按钮和搜索框都应优先可见，不能被辅助信息挤出首屏。

## 交互反馈

- 保存、推进、收款、导出后使用轻量 SnackBar 或页面内状态反馈。
- 删除、恢复备份、载入演示数据均二次确认。
- 离线状态用顶部警示条表达，不阻断已加载的本地功能。
- 空状态提供下一步动作，不只显示“暂无数据”。

- [ ] 颜色在浅色 / 深色模式下都有足够对比度。
